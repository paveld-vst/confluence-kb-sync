# Confluence KB Sync

Confluence KB Sync — это простой инструмент для синхронизации
выбранных страниц Confluence Cloud в локальную базу знаний
в удобном для AI формате.

Эта база знаний автоматически используется AI Copilot
в IDE JetBrains (RubyMine, IntelliJ IDEA, WebStorm, PyCharm),
что позволяет получать ответы по внутренней документации
без открытия Confluence в браузере.

---

## Зачем нужен этот инструмент

Во многих командах важная техническая информация хранится в Confluence:
- API контракты
- пользовательские флоу
- описания функциональности
- настройки окружений

На практике это приводит к проблемам:
- неудобный поиск в Confluence
- постоянное переключение между IDE и браузером
- AI Copilot не имеет прямого доступа к Confluence

Этот инструмент решает проблему, преобразуя страницы Confluence
в локальные Markdown-файлы, которые IDE автоматически индексирует
и использует как контекст для AI Copilot.

---

## Основные возможности (MVP v0.1)

- Ручная синхронизация страниц Confluence Cloud
- Структура по категориям (API, flows, features, misc)
- Чистый Markdown-формат
- AI-friendly обёртка документов (заголовок, источник, дата)
- Общая база знаний для нескольких проектов
- Подходит для QA инженеров и разработчиков
- Поддержка RU/EN запросов:
  - документация на английском
  - вопросы и ответы — на русском или английском

---

## Как это работает

1. QA или разработчик указывает URL страниц Confluence по категориям
2. Инструмент загружает содержимое через Confluence REST API
3. HTML автоматически конвертируется в Markdown
4. Страницы сохраняются в локальную базу знаний
5. Проекты подключают эту базу знаний через symlink
6. AI Copilot автоматически использует документацию как контекст

## Требования

- Python версии 3.9 или выше
- Доступ к Confluence Cloud
- API токен Confluence
- IDE JetBrains с AI Copilot (рекомендуется)

---

## Установка

1. Склонировать репозиторий:

	git clone <repository-url>
	
2. Установить зависимости:

	pip install -r requirements.txt
	
3. Настроить доступ к Confluence:
- отредактировать `config/config.yaml`
- указать email и API токен

4. Указать страницы для синхронизации:
- отредактировать `config/pages.yaml`
- сгруппировать URL по категориям

---

## Использование

Запуск синхронизации вручную:
	
	python src/main.py
	
После выполнения Markdown-файлы будут созданы
в указанной директории базы знаний.

---

## Использование с AI Copilot

1. Создайте symlink с именем `.kb` в корне проекта,
   указывающий на директорию базы знаний
2. Откройте проект в IDE JetBrains
3. Задавайте вопросы в чате AI Copilot, например:
   - «Согласно нашей API-документации, как работает авторизация?»
   - «Какие флоу логина описаны в документации?»

AI Copilot автоматически будет использовать
локальную документацию как контекст.

---

## Безопасность

- Никогда не коммитьте `config/config.yaml` с токенами
- Не добавляйте базу знаний в Git
- Используйте `.gitignore` для локальных файлов
